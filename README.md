# XML-фид КП «Счастье» для ЦИАН и Домклика

Фид в формате **Циан 2.0**: 6 домов и 2 участка, перенесённые с Авито. Домклик принимает фиды в формате Циан, поэтому один фид подходит обеим площадкам.

**Ссылка на фид:** https://dpoleschukbm-creator.github.io/kp-schastye-feed/feed.xml

**Все фото с номерами:** https://dpoleschukbm-creator.github.io/kp-schastye-feed/photos.html — номер на фото = его место в объявлении, №1 — главное.

## Работа с другого компьютера

Всё нужное лежит в этом репозитории. На компьютере нужны только **Git for Windows** и **Claude Code**. Python для сборки Claude при необходимости скачает сам.

1. Скачать репозиторий:
   ```
   git clone https://github.com/dpoleschukbm-creator/kp-schastye-feed.git
   ```
2. Открыть папку `kp-schastye-feed` в Claude Code и написать, что поменять. Например: «Дом 100 м²: цена 9 млн, фото 3 заменить на файл из загрузок такой-то».
3. Claude сам прочитает `CLAUDE.md` (там вся инструкция), внесёт правки, пересоберёт и опубликует фид. Если Python на компьютере нет, он скачает портативный сам.

Скачать можно без входа (репозиторий публичный). При первой публикации с нового компьютера git попросит войти в GitHub (аккаунт `dpoleschukbm-creator`) — окно входа откроется само, войти нужно вам. Пароли и токены в чат не вставляйте.

Если репозиторий уже скачан раньше, перед правками обновить его: `git pull`.

## Как подключить

| Площадка | Где | Что сделать |
|---|---|---|
| ЦИАН | Личный кабинет → «Импорт объявлений» / «Настройка фида» | Вставить ссылку на фид. Нужен бизнес-аккаунт (агентство/застройщик) |
| Домклик | Личный кабинет партнёра → «Разместить фид» | Вставить ссылку, дать фиду имя, «Сохранить». Доступно ролям «Руководитель компании» / «Руководитель офиса» |

Изменения подтягиваются: ЦИАН — при очередном обходе фида, Домклик — в течение 2 часов.

## Как изменить объявление

1. Поправить данные в `data/objects.json` (цена, площадь, материал стен и т. п.) или текст в `data/avito_media.json`.
2. Пересобрать: `python build.py` (с `--photos` — если нужно докачать фото).
3. Закоммитить и запушить — GitHub Pages обновит фид за 1–2 минуты.

**Снять объект с публикации** — удалить его из `data/objects.json`, пересобрать и запушить.

**Заменить фото** — ЦИАН игнорирует новое изображение по старой ссылке, поэтому новое фото кладите под новым именем файла. Порядок фото = сортировка имён файлов, первое — главное (например, `01-plan100.jpg` встаёт перед `02.jpg`). Старый файл удалите и впишите его имя в `removedPhotos` объекта в `data/objects.json`, чтобы `--photos` не скачал его с Авито заново.

## Структура

| Путь | Что это |
|---|---|
| `data/objects.json` | Параметры объектов (цена, площади, материал, вода и т. д.) |
| `data/avito_media.json` | Исходные описания и ссылки на фото с Авито |
| `build.py` | Сборка фида: чистка текстов, дедупликация фото, генерация XML и страницы с фото |
| `docs/feed.xml` | Готовый фид (публикуется через GitHub Pages) |
| `docs/photos.html` | Страница со всеми фото и их номерами (собирается вместе с фидом) |
| `docs/photos/<id>/` | Фото объектов |
| `CLAUDE.md` | Инструкция для Claude: как править фид, правила ЦИАН/Домклика, текущее состояние |

## Что заполнено по умолчанию

- Контакт: +7 (903) 801-88-08; коттеджный посёлок «Счастье»; координаты посёлка.
- Все объекты: ИЖС, земли населённых пунктов, газ магистральный, септик, электричество, ипотека возможна.
- Дома: состояние «без внутренней отделки» (white box), ремонт — без ремонта, отопление — автономное газовое. Для отдельного дома переопределяется полями `"repair"` (`cosmetic` / `euro` / `design` / `no`) и `"condition"` (`ready` / `interiorDecorationRequired` / `majorRepairsRequired` / `unfinished`) в `data/objects.json`. Тип ремонта должен соответствовать фото (требование ЦИАН).
- Кадастровые номера не указаны (тег `CadastralNumber` необязателен, но ЦИАН за него даёт отметку проверки).
