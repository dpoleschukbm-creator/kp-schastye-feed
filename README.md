# XML-фид КП «Счастье» для ЦИАН и Домклика

Фид в формате **Циан 2.0**: 6 домов и 2 участка, перенесённые с Авито. Домклик принимает фиды в формате Циан, поэтому один фид подходит обеим площадкам.

**Ссылка на фид:** https://dpoleschukbm-creator.github.io/kp-schastye-feed/feed.xml

## Как подключить

| Площадка | Где | Что сделать |
|---|---|---|
| ЦИАН | Личный кабинет → «Импорт объявлений» / «Настройка фида» | Вставить ссылку на фид. Нужен бизнес-аккаунт (агентство/застройщик) |
| Домклик | Личный кабинет партнёра → «Разместить фид» | Вставить ссылку, дать фиду имя, «Сохранить». Доступно ролям «Руководитель компании» / «Руководитель офиса» |

Изменения подтягиваются: ЦИАН — при очередном обходе фида, Домклик — в течение 2 часов.

## Как изменить объявление

1. Поправить данные в `data/objects.json` (цена, площадь, материал стен и т. п.) или текст в `data/avito_media.json`.
2. Пересобрать: `python build.py` (с `--photos` — если нужно докачать фото).
3. Закоммитить и запушить — GitHub Pages обновит фид за 1–2 минуты.

**Снять объект с публикации** — удалить его из `data/objects.json`, пересобрать и запушить.

**Заменить фото** — ЦИАН игнорирует новое изображение по старой ссылке, поэтому новое фото кладите под новым именем файла.

## Структура

| Путь | Что это |
|---|---|
| `data/objects.json` | Параметры объектов (цена, площади, материал, вода и т. д.) |
| `data/avito_media.json` | Исходные описания и ссылки на фото с Авито |
| `build.py` | Сборка фида: чистка текстов, дедупликация фото, генерация XML |
| `docs/feed.xml` | Готовый фид (публикуется через GitHub Pages) |
| `docs/photos/<id>/` | Фото объектов |

## Что заполнено по умолчанию

- Контакт: +7 (903) 801-88-08; коттеджный посёлок «Счастье»; координаты посёлка.
- Все объекты: ИЖС, земли населённых пунктов, газ магистральный, септик, электричество, ипотека возможна.
- Дома: состояние «без внутренней отделки» (white box), ремонт — без ремонта, отопление — автономное газовое.
- Кадастровые номера не указаны (тег `CadastralNumber` необязателен, но ЦИАН за него даёт отметку проверки).
